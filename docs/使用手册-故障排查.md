# 使用手册 · 故障排查

读完本篇你能：对常见异常按「现象 → 原因 → 操作」快速定位。所有命令为 Windows PowerShell 可直接复制执行；标注 ✅ 的条目含本机实测证据。

> 通用排查套路：① 看 `/healthz` 的 `capabilities` 与 `degraded`；② 看响应头 `X-Request-Id` 并对照后端 stdout 日志同一 `request_id`；③ 每个错误响应都带 `error` / `reason` 字段，先按它在下表检索。

## 排查表

| # | 现象 | 原因 | 操作 |
|---|---|---|---|
| 1 ✅ | `/healthz` 返回 200 且 `status=degraded`、`missing` 列出 postgres/redis | 无 PG/Redis，degraded 降级运行（支持模式，2026-11-04 起三态语义：进程可服务即 200） | 无需处理；接齐 PG/Redis 后 5s 内自动转 `status=ok`。若配置了 `health.require_dependencies=true` 则缺依赖返回 503（旧行为）。验证：`curl.exe -i http://127.0.0.1:8795/healthz` |
| 2 ✅ | 开播 503，`reason=engine_unavailable`，message 含 `engine_not_configured: missing_credentials: DH_VIDU_KEY,DH_OMNIVOICE_ADDR` | 默认 `engine.mode=real` 且未注入凭据（fail-closed，设计如此） | 设置 `$env:DH_VIDU_KEY="..."; $env:DH_OMNIVOICE_ADDR="http://..."` 后重启；本机联调用 `$env:DH_ENGINE_MODE="dev"`（启动日志应出现 `WARN using fake live controller`） |
| 3 | 舞台区显示「RTC 未配置（后端未下发凭据）」 | `rtc.mode=disabled`（默认），属正常状态 | 需要画面时设 `DH_RTC_MODE=dev` + `DH_RTC_API_KEY`/`DH_RTC_API_SECRET` 重启 |
| 4 | 前端事件流断线，`ticket_invalid_or_used` | WS ticket 过期（默认 60s）/ 已使用 / 跨场次复用 | 前端会自动重取重连；手动验证：`curl.exe -X POST "http://127.0.0.1:8795/api/v1/ws-ticket?session_id=<sid>"` 取新票 |
| 5 ✅ | lan 模式全部接口 401 `{"error":"unauthorized"` | Bearer 缺失或 token 与 `admin_token_sha256` 不匹配 | 重新计算哈希（配置篇 §4.2 命令）；前端顶部重新「应用」token |
| 6 | 远端访问 403 `loopback_only` | `security.mode=local` 只允许回环 | 改 `lan` 模式并配 token，或回源到本机操作 |
| 7 | 浏览器请求 403 `origin_not_allowed` | Origin 不在白名单 | 把前端源（含端口）加入 `security.allowed_origins`，注意不带末尾斜杠差异已被归一 |
| 8 ✅ | 保存设置 409 `settings_revision_conflict`（`base=… current=…`） | 别人/另一标签页先保存过 | 抽屉底部点「重载」刷新后重新修改保存 |
| 9 ✅ | 保存设置 409 `settings_validation_failed: 必须提交全部 13 组设置` | 只提交了部分分组（自行调 API 时常见） | 前端不存在此问题；自写脚本需回传全部 13 组 |
| 10 | 保存设置 409，`danmaku.mode 必须是 off/confirm/auto` | 弹幕模式取值非法 | 改回三选一 |
| 11 | 歌曲/音频上传失败 | multipart 过大、目录无权限或路径不在白名单 | 歌曲走 `/api/v1/songs/upload`；文件夹导入只允许 `storage/` 之下的绝对路径；检查目录写权限 |
| 12 | TTS 试听/口播合成超时或失败 | OmniVoice 边车未接入（`capabilities.omnivoice=false`） | 先确认 `$env:DH_OMNIVOICE_ADDR` 已设且边车在线；前端默认请求超时 10s，超时报「请求超时（10s）」 ⚠️ 边车联调未验证 |
| 13 ✅ | 后端启动失败 `bind: Only one usage of each socket address ...` | 8795 已被占用（如已有 dh 实例在跑） | `netstat -ano \| findstr :8795` 找进程；或改配置 `server.http_addr` 换端口 |
| 14 | 前端白屏 | 后端不可达不会白屏（有错误态）；白屏多为前端构建/代理问题 | 确认 `npm run dev` 在 9000 且代理目标 8795 在跑；生产构建需自行托管 `web/dist/spa` 并反代 `/api`、`/ws`；按 F12 看 Console 报错 |
| 15 | `/metrics` 403 `metrics_local_only` | metrics 仅允许回环 | 在本机 curl；勿对公网开放 |
| 16 | 采集器上报 401 `collector_signature_invalid` | HMAC 签名错 / 时间窗超 300s / nonce 重放 | 按配置篇 §4.3 核对签名串拼接（method+path+sha256(body)+ts+nonce，`\n` 连接）、校时、换 nonce；注意改 body 后必须重签 |
| 17 | 复盘面板为空 / 重启后历史消失 | 无 PG，内存存储重启即丢 | 配 `data.postgres_dsn`；文件兜底仅有 `storage/cost/ledger.json`（账本）与 `storage/koubo/project.json`（口播） |
| 18 | 事件流 REST 与 WS 对不上 | 设计上同源（同一 sink），正常不应分叉 | 用 `after_seq` 重放核对；降级期（PG 未接）内存上限 4096 条，超出部分在 PG 接入后无法补写——这是已知丢失边界 |
| 19 | curl 调接口报 400 `CODEC ... invalid value <字段名>` | **PowerShell 把 JSON 双引号吞了**（不是接口问题）；接口字段 snake_case 与 camelCase 均接受 | 把 body 写入临时文件再发：`curl.exe -X POST <url> -H "Content-Type: application/json" --data-binary "@body.json"` ✅（实测：`--data-binary` 方式 camelCase 正常解析） |
| 20 | 界面时间/导出文件时间戳对不上 | 接口统一 epoch 毫秒（UTC），日志为本地时区 ISO8601 | 换算时注意 `ts_ms` 是 UTC epoch ms；导出 CSV 同口径 |
| 21 | 弹幕不播报 | `danmaku.mode=off`（默认） | 弹幕面板「应用模式」切 confirm/auto；或设置组「弹幕主播模式」保存后点「重载」（该组即时生效） |
| 22 | 战绩/积分一直「—」 | 无 Vidu 凭据，credits 轮询与账本来源不可用 | 属预期；`misc.credits_balance` 只读 ⚠️ 未验证 |
| 23 | 进程重启后场次显示 `error(crash_recovered)` | 崩溃恢复逻辑：重启时不属于本进程的 starting/live/stopping 场次被标记 error，不自动续播 | 复盘面板确认事件与成本后手动重新开播 |
| 24 | `go build` 失败 | Go 版本 < 1.26 或依赖未拉取 | `go version` 确认；`go mod tidy` 后重试（lockfile 只认 go.sum，勿混用代理残留） |
| 25 | `npm run build` 失败 | 依赖未装或用了 pnpm | `cd web; npm install`（本仓库不使用 pnpm）；`npm run typecheck` 先排类型错误 |

## 常用诊断命令速查

```powershell
# 健康与能力
curl.exe -i http://127.0.0.1:8795/healthz

# 当前场次状态（phase / feed.owner / ws.state / eventSeq）
curl.exe http://127.0.0.1:8795/api/v1/live/status

# 场次列表与导出
curl.exe http://127.0.0.1:8795/api/v1/sessions
curl.exe -OJ "http://127.0.0.1:8795/api/v1/sessions/<id>/export?format=csv"

# 端口占用
netstat -ano | findstr :8795

# lan 模式带 token 访问
curl.exe -H "Authorization: Bearer <token>" http://127.0.0.1:8795/api/v1/live/status
```
