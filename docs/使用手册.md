## 60 秒了解当前状态

1. 后端为 Go（Kratos）单进程，前端为 Quasar 工程壳 + 自研组件，默认监听 `127.0.0.1:8795`，前端开发服务器在 `http://localhost:9000`。
2. **当前默认 fail-closed**：没有 Vidu Key 和 OmniVoice 边车地址时，点「开始直播」会得到 `503 engine_unavailable`。这不是故障，是设计如此——绝不用假数据冒充开播成功。想本机体验界面流程，可显式设 `DH_ENGINE_MODE=dev` 使用假引擎（日志会有 `WARN using fake live controller` 字样）。
3. 没有 PostgreSQL / Redis 也能启动（degraded 降级模式，属支持的运行方式）：`/healthz` 默认仍返回 200，以 `status=degraded` + `missing` 名单显式标注缺失依赖（`health.require_dependencies=true` 时恢复旧行为返回 503）；场次/事件/设置改为进程内存保存，**重启即丢**。
4. RTC 画面凭据默认 `disabled`，界面显示「RTC 未配置」属正常，不是错误。

## 界面速览

```
┌──────────────────────────────────────────────────────────────┐
│ 小雅·数字人直播台   [Bearer输入] [全部设置] [快捷设置]          │
├──────────────────────────────────────────────────────────────┤
│ 面板栏：声音 动作 弹幕 口播 参考图 歌曲 复盘 ｜ 字幕/事件        │
├───────────────────────────────────────────┬──────────────────┤
│ 舞台区（RTC 画面 + 字幕层 + 开始/停止按钮）  │ 右栏：字幕 / 事件  │
│ （各面板以浮窗形式叠在舞台区上）             │                  │
├───────────────────────────────────────────┴──────────────────┤
│ 输入条：说点什么 / 指令 / 打断 / 停止                           │
├──────────────────────────────────────────────────────────────┤
│ 统计条：积分 Token 钻石 礼物 时长 音频延迟                       │
└──────────────────────────────────────────────────────────────┘
```

- 页面路由共 6 条：`/`（直播台）、`/settings`（全部设置 + 界面偏好）、`/platform`（平台）、`/avatars`（形象档案）、`/avatars/new`（新建形象）、`/avatars/:id/edit`（编辑形象）。
- 快捷键：`F9` 开播；`F10` 只打开「下播确认」，显式激活「确认下播」后才停止，`Esc` / 取消保持直播中。
